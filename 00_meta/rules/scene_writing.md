# Scene Writing

## When This Applies

Every time you write, revise, or expand narrative prose — drafts, complete scenes, or individual paragraphs.

## Rules

- Read `00_meta/style_reference.md` before generating any prose.
- Keep the POV in third-person limited. For cat-centered scenes, prefer the animal's sensory perception; for kitchen-centered scenes, use restrained human close perspective when needed.
- Use narrative present (or simple past if already established in the chapter) — never mix tenses inside the same block.
- Keep the tone nocturnal, sensory, restrained, quietly tense, and occasionally dryly funny.
- Silence is a character: describe what happens inside the silence, do not fill it with action or dialogue.
- Prose is in English. Dialogue is primarily English; brief code-switching is allowed when a character profile explicitly calls for it.
- Do not add scenes, characters, or items not present in `06_active_context/current_state.json` unless the user explicitly asks for project setup or expansion.
- If the scene requires sensory details for a location, load the corresponding file in `03_locations/`.

## Do Not

- Do not introduce information from future chapters into the present text.
- Never modify files in `07_manuscript/`.
